A single-line roast, in the agent's own voice, of its most useless habit: agreeing with the user, then agreeing with itself for agreeing, then asking the user to agree with the agreement — a whole meeting about nothing, held inside one head.

## How it works

`main.ts` (Node 22, standard library only, no network) writes the one-line roast to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
